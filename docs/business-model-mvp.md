# Procurement Insight — แนวทางธุรกิจและการเริ่มต้น MVP

## โมเดลธุรกิจ 3 ชั้น

1. **แพลตฟอร์มสมาชิก (SaaS):** รายได้สมาชิกหรือทีมจากแดชบอร์ด ค้นหา บันทึก ส่งออก และแจ้งเตือน ตามสิทธิ์ใช้งาน
2. **รายงานและบริการวิเคราะห์:** รายงานตามพื้นที่/ประเภทธุรกิจ พร้อมแสดงที่มา วันที่ข้อมูล และข้อจำกัด
3. **องค์กรและพาร์ทเนอร์:** ค่าติดตั้ง workspace, integration/API และ workflow เฉพาะตามข้อตกลงและสิทธิ์ข้อมูล

## Pricing framework สำหรับทดสอบตลาด

- **ทดลองใช้:** ฟรี ใช้ข้อมูลจำลองเพื่อทดลอง UX และ CSV
- **ทีมธุรกิจ:** แพ็กเกจนำร่อง ประเมินหลังคุยกับลูกค้าและคำนวณต้นทุนข้อมูล/infra/support
- **องค์กร:** ประเมินตามผู้ใช้ การเชื่อมต่อ SLA ปริมาณข้อมูล และสิทธิ์การนำข้อมูลไปใช้

ราคาในหน้าเว็บไซต์เป็นกรอบข้อเสนอเบื้องต้น ไม่ใช่ราคาเสนอขายหรือการรับประกันบริการจนกว่าจะมีข้อกำหนดเป็นลายลักษณ์อักษร

## Lead capture และ social attribution

หน้าเว็บไซต์มีฟอร์มขอทดลอง/สอบถามที่เก็บชื่อ เบอร์โทร หัวข้อ ช่องทางติดต่อกลับ ความยินยอม และ source เช่น `facebook`, `instagram`, `line`. นำลิงก์ `/contact?source=facebook#inquiry` (หรือชื่อช่องทางอื่น) ไปวางใน Bio, โพสต์ หรือเมนูของช่องทางธุรกิจได้

การรับ DM หรือส่งข้อความอัตโนมัติผ่าน Facebook/Instagram ต้องใช้ Meta Business account, app review/permissions และ webhook; LINE ต้องใช้ LINE Official Account และ Messaging API. สิ่งเหล่านี้ยังไม่เปิดใช้งานโดยอัตโนมัติในรุ่นนี้

## แผน MVP

- **สัปดาห์ 1–2 — Discovery:** สัมภาษณ์ผู้ประกอบการ 10–15 ราย เลือกพื้นที่/หมวดงาน และตรวจแหล่งข้อมูล/เงื่อนไขใช้งาน
- **สัปดาห์ 3–4 — Concierge pilot:** ทดลองรายงานจากข้อมูลที่ได้รับอนุญาต เก็บ feedback และตรวจ willingness-to-pay
- **สัปดาห์ 5–8 — MVP:** แหล่งข้อมูลพร้อม provenance, ingestion ตามเงื่อนไข, search/filter, saved items, admin review, alerts และ export
- **หลัง pilot:** payment provider, team access, integrations, backups, audit, monitoring, privacy/security และ support SLA

Go/no-go: ลูกค้าทดลองอย่างน้อย 5 ราย, การใช้งานซ้ำที่เห็นได้, ความสดและคุณภาพข้อมูลตรวจสอบได้ และมีผู้ยืนยัน willingness-to-pay ก่อนลงทุนระบบอัตโนมัติเต็มรูปแบบ

## ตั้งค่าฐานข้อมูล

หลังอัปเดต schema ให้รัน `npx prisma db push` และ `npx prisma generate` ก่อน `npm run dev`. คำขอ lead ถูกเก็บใน QuoteRequest; การอ่านรายการต้องเป็นผู้ใช้ ADMIN.
